# Pointwise convergence for two commuting transformations

A Lean 4 / Mathlib formalization of `blueprint/commuting_ergodic_blueprint.tex`. All nodes from
A01 to T08 are proved. The proofs contain no `sorry`, and the main theorem depends only on the
standard axioms `propext`, `Classical.choice` and `Quot.sound`. Everything is in the namespace
`Auto`, in `TwoCommuting/Auto/`, with one file per blueprint section (§2–§10).

## Main theorem (Thm 10.3, node T08)

Let `(X, μ)` be an arbitrary probability space and let `T, S : X → X` be commuting measurable
measure-preserving maps. Let `1 ≤ p, q ≤ ∞` with `1/p + 1/q ≤ 1`, and let `f ∈ L^p(μ)`,
`g ∈ L^q(μ)` be complex-valued. Then the averages

  `A_N(f,g)(x) = (1/N) ∑_{n=0}^{N-1} f(Tⁿx) g(Sⁿx)`

have the following convergence properties:

1. They converge to a finite limit for μ-almost every `x`.
2. If `1/r = 1/p + 1/q > 0`, they converge in `L^r(μ)`.
3. If `p = q = ∞`, they converge in `L^r(μ)` for every finite `r ≥ 1`.

Neither ergodicity nor invertibility is assumed.

Lean: `Auto.commuting_ergodic_averages_converge_main`, in
[`Sec10IntegrableExtension.lean`](TwoCommuting/Auto/Sec10IntegrableExtension.lean):

```lean
theorem commuting_ergodic_averages_converge_main {X : Type u} [MeasurableSpace X]
    {μ : Measure X} [IsProbabilityMeasure μ] {T S : X → X}
    (hT : MeasurePreserving T μ μ) (hS : MeasurePreserving S μ μ) (hTS : T ∘ S = S ∘ T)
    {p q : ℝ≥0∞} (hp : 1 ≤ p) (hq : 1 ≤ q) (hpq : p⁻¹ + q⁻¹ ≤ 1) {f g : X → ℂ}
    (hf : MemLp f p μ) (hg : MemLp g q μ) :
    (∀ᵐ x ∂μ, ∃ L, Tendsto (fun N => bilinAvg T S f g N x) atTop (𝓝 L)) ∧
    (0 < p⁻¹ + q⁻¹ → ∃ F, MemLp F (p⁻¹ + q⁻¹)⁻¹ μ ∧
      Tendsto (fun N => eLpNorm (bilinAvg T S f g N - F) (p⁻¹ + q⁻¹)⁻¹ μ) atTop (𝓝 0)) ∧
    (p = ⊤ → q = ⊤ → ∀ r : ℝ, 1 ≤ r → ∃ F, MemLp F (ENNReal.ofReal r) μ ∧
      Tendsto (fun N => eLpNorm (bilinAvg T S f g N - F) (ENNReal.ofReal r) μ) atTop (𝓝 0))
```

Here `bilinAvg T S f g N x = (N : ℂ)⁻¹ * ∑ n ∈ Finset.range N, f (T^[n] x) * g (S^[n] x)`.
This is defined in
[`Sec9DiscreteTransformations.lean`](TwoCommuting/Auto/Sec9DiscreteTransformations.lean).

## Principal intermediate results

- **Bounded inputs (Thm 9.4, T05):** `Auto.bounded_commuting_averages_ae`, in §9. For bounded
  measurable `f, g`, the averages `A_N(f,g)` converge almost everywhere, to a single limit `F`.
  They also converge to `F` in every `L^r` with `1 ≤ r < ∞`.
- **Commuting real flows (Thm 8.2, S02):** `Auto.S02_holds : S02Statement`, in §8. Let `U, V` be
  commuting, jointly measurable, measure-preserving real flows (`CommutingFlows`), and let
  `f, g` be bounded measurable. Then `R⁻¹ ∫₀^R f(U^t ω) g(V^t ω) dt` converges as `R → ∞`, for
  almost every `ω`.
- **Euclidean counting estimate (Thm 6.1, E01):** `Auto.Euclidean_counting_bound`, in §6. There
  is an absolute constant `C` with the following property. For `m ∈ {3, 4}`, `n ≥ 1` and
  measurable `F, G ∈ L³(ℝ²)`,

  `(∫⁻ (S_n^{(m)}(F,G))^{3/2})^{2/3} ≤ C √n ‖F‖₃ ‖G‖₃`.

  Here `S_n^{(m)}(F,G)` is the supremum, over at most `n` disjoint rational intervals `(u,v)`,
  of `∑ |B_{K^{(m)}_{u,v}}(F,G)|`. The flow version (Prop 7.1, F01) is
  `Auto.flow_counting_bound`, in §7.
