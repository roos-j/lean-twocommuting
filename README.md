# Pointwise convergence of ergodic averages with respect to two commuting transformations

This is a Lean 4 formalization of the following theorem:

Let $`(X, \mu)`$ be a probability space and
$`T, S`$ two commuting measure preserving transformations $`X → X`$.
Then for every $`f ∈ L^p(\mu), g ∈ L^q(\mu)`$ with $`p, q ∈ [1,\infty]`$ and $`p⁻¹ + q⁻¹ ≤ 1`$ the averages
```math
A_N(f,g)(x) = N^{-1} \sum_{n=0}^{N-1} f(T^n x) g(S^n x)
```
converge for a.e. `x` as `N → ∞`.

The Lean statement is in [`Theorems.lean`](TwoCommuting/Theorems.lean).
